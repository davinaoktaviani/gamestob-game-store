# GameStoB — Game Store Website

A front-end game store website built with **HTML, CSS, and JavaScript**. GameStoB provides a multi-page shopping experience for browsing games and DLCs, filtering products, viewing store locations, and completing a simulated purchase process.

---

## Project Overview

**GameStoB** is a game store website designed to provide users with a simple and interactive platform for discovering and purchasing games.

The website includes several pages that represent different parts of a game store experience, from browsing the homepage and product catalog to completing a purchase and finding physical store locations.

---

## Features

### 🏠 Home

* Promotional hero section
* Featured game of the day
* Latest releases
* Best sellers
* New DLC releases
* Store highlights

### 🎮 Product Catalog

* Game search
* Genre filtering
* Platform filtering
* Price sorting
* Product cards with game information
* Direct navigation to the purchase page

### 💳 Purchase

* Game selection
* Customer information form
* Payment method selection
* Bank selection for bank transfer
* Payment-related form interactions

### ℹ️ About Us

* Information about GameStoB
* Store highlights
* Services and customer experience information

### 📍 Store Locations

* Physical store locations
* Store information
* Opening hours
* Contact information

### 📱 Responsive Navigation

* Navigation menu across pages
* Mobile menu toggle
* Responsive layout for different screen sizes
